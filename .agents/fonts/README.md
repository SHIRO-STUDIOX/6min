# راهنمای فونت IRANYekanX Variable Font

این پوشه شامل اسناد راهنمای وب‌فونت ایران‌یکان X است.

## فایل‌های راهنما:
* [IranYekanX Help.html](./IranYekanX%20Help.html): سند رسمی راهنمای استفاده و ویژگی‌های وریبل فونت ایران‌یکان X
* [IRANYekanXV test.html](./IRANYekanXV%20test.html): صفحه نمونه تست تعاملی فونت

## متغیرهای اصلی (font-variation-settings):
* **ضخامت (`"wght"`):** از `100` تا `1000`
* **تیزی دندانه‌ها و نقطه‌ها (`"dots"`):** از `0` تا `4`

## ویژگی‌های OpenType (font-feature-settings):
* **`ss02`:** فارسی‌سازی اعداد انگلیسی و عربی
* **`ss03`:** هم‌عرض (Monospace) کردن اعداد در جدول‌ها و لیست‌ها

## محل فایل‌های فعال وب در پروژه:
* `public/fonts/IRANYekanXVF.woff2`
* `public/fonts/IRANYekanXVF.woff`
* `public/fonts/staticfonts/IRANYekanX-Regular.woff`
* `public/fonts/staticfonts/IRANYekanX-Bold.woff`
