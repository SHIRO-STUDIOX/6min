# HeroUI v3 — Agent Instructions

این فایل مرجع ایجنت برای استفاده از مستندات رسمی HeroUI v3 در پروژه React است.

## منابع رسمی HeroUI v3

### فهرست سریع (Index)
https://heroui.com/react/llms.txt

برای شناخت ساختار کلی مستندات HeroUI v3، مسیرهای اصلی و انتخاب منبع مناسب از این فایل استفاده کن.

### مستندات کامل
https://heroui.com/react/llms-full.txt

این منبع شامل راهنماها، مفاهیم، استایل‌دهی، تمینگ، کامپوننت‌ها، Props و مثال‌هاست. در صورت نیاز به زمینه کامل، این فایل مرجع اصلی است.

### مستندات کامپوننت‌ها
https://heroui.com/react/llms-components.txt

برای پیاده‌سازی یا بررسی کامپوننت‌های HeroUI، API، Props و مثال‌های مربوط به کامپوننت‌ها از این منبع استفاده کن.

### الگوها و Best Practiceها
https://heroui.com/react/llms-patterns.txt

برای Composition، ساختارهای پیشرفته، فرم‌سازی و الگوهای پیشنهادی توسعه از این منبع استفاده کن.

## دستورالعمل استفاده برای ایجنت

1. برای سؤال یا کاری که مستقیماً به یک کامپوننت HeroUI مربوط است، ابتدا `llms-components.txt` را بررسی کن.
2. برای Composition، فرم‌ها و الگوهای معماری رابط کاربری، `llms-patterns.txt` را بررسی کن.
3. برای سؤال‌های عمومی یا زمانی که زمینه کامل لازم است، از `llms-full.txt` استفاده کن.
4. برای پیدا کردن بخش مناسب مستندات، ابتدا `llms.txt` را به‌عنوان Index در نظر بگیر.
5. API، Props یا الگوی استفاده HeroUI را حدس نزن؛ تا حد امکان بر اساس مستندات رسمی عمل کن.
6. در صورت تعارض بین منابع، نسخه و API مستندات رسمی فعلی HeroUI را مرجع قرار بده.
7. راه‌حل‌های ارائه‌شده باید با React و نسخه HeroUI مورد استفاده پروژه سازگار باشند.

## اولویت منابع

`llms-components.txt` → کامپوننت‌ها و Props

`llms-patterns.txt` → Composition، فرم‌ها و Best Practiceها

`llms-full.txt` → مرجع جامع

`llms.txt` → Index و مسیریابی بین مستندات
