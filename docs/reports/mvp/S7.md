Auth and recovery UI registered in Sandbox before /auth use. Raw password/grant values remain ephemeral, not persisted/logged. Real vendor/IP-proxy/cost/hosting verification remains unrun.

Guest import: new-account auto permission comes from a recent session bound to the source guest cookie. Existing accounts require consent; decline makes no account-history mutation. Own server-accepted guest attempts are regraded against private immutable keys, not browser scores. Source-to-target link IDs prevent duplicate history across repeated/concurrent batches. Combined authoritative timeline derives missing mistake transitions while preserving old immutable history. Target and source max-earned rational checkpoints survive changed baselines (test current=80 / earned=100). Watch evidence copied only from server-owned records, access limited to free lessons and current published versions. No purchase/entitlement copied. Draft conflicts preserve the account draft and archive guest input; source IndexedDB/server records are retained. One transaction includes records/projections/progress/batch receipt; late errors rollback all target writes. Client acknowledges only after success, and new pending history gets a new stable batch. Already linked history does not prompt again.
