# ADR-011 — Private development profile assets

Use existing Sharp 0.34.5 as an explicit pinned dependency (already installed by Next) for raster decoding, 16M pixel limit, metadata stripping and maximum512px PNG output. Bound raw uploads to2MiB before decode; reject SVG, animations, malformed images and unsupported formats. Never trust filenames or remote user URLs. Random asset UUIDs, database ownership, owner-only authenticated no-store reads and filesystem permissions0600. Replacement writes bytes first, then DB reference transaction; errors retain the previous reference. Unreferenced and removed assets retained pending privacy retention decision; no physical deletion authorized.

Storage adapter uses ignored .local-data under guarded development/test only, separate test namespace. Production fails closed until private object storage, backup and retention configuration approved. This is working local persistence, not operational production asset hosting. Profile updates accept only trimmed bounded displayName; client cannot set phone/auth/entitlement/avatar keys. Existing progress is read from the shared server projection. HeroUI v3 TextField and Avatar docs consulted. No visual redesign approval implied.
